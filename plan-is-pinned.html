Is Pinned Field Feature

COMPLETED Added is_pinned field to projects with SVG pin buttons and creation date sorting.

Overview

Added an is_pinned boolean field directly to the projects table. Pinned projects appear at the top of the list, while unpinned projects are sorted by creation date. Each project now has an SVG pin button for toggling the pin state.

Changes Made

1. Database Model

backend/models.py

class Project(models.Model):
    id = fields.UUIDField(pk=True, default=uuid.uuid4)
    user = fields.ForeignKeyField("models.User", ...)

    description = fields.TextField(null=True)
    is_pinned = fields.BooleanField(default=False)  # NEW
    created_at = fields.DatetimeField(auto_now_add=True)

3. Backend API

backend/routes/projects.py

  • GET /api/projects: Reads is_pinned directly from Project model. Sorts pinned first, then by creation date.
  • POST /api/projects/{id}/pin: Sets project.is_pinned = True and saves.
  • DELETE /api/projects/{id}/pin: Sets project.is_pinned = False and saves.
# Sorting logic
project_responses.sort(key=lambda r: (not r.is_pinned, r.created_at))

5. Schema Reference

backend/schema.sql

CREATE TABLE IF NOT EXISTS projects (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    name TEXT NOT NULL,
    description TEXT,
    is_pinned BOOLEAN DEFAULT FALSE,  -- NEW
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

Behavior

  • Default: All projects have is_pinned = false
  • Pin: Click the pin button to set is_pinned = true
  • Unpin: Click the pin button again to set is_pinned = false
  • Sort Order: Pinned projects first, then by creation date (oldest first)
