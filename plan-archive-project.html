Archive Project Feature

Add the ability to archive and unarchive projects, soft-deleting them from the active project list.

Goal

Users should be able to archive projects they no longer actively use, hiding them from the default project list while preserving all associated data. Archived projects can be unarchived to restore them.

Execution Phases

Phase 1: Database Model & Migration

  • Add is_archived = fields.BooleanField(default=False) to Project in db.py
  • Create migration backend/migrations/0002_project_archive.py

Phase 2: Backend API Endpoints

  • Add is_archived to ProjectResponse model
  • Add POST /{project_id}/archive endpoint
  • Add POST /{project_id}/unarchive endpoint
  • Filter out archived projects from GET /api/projects list by default

Phase 3: CLI Commands

  • Add archive_project and unarchive_project methods to PlanAPI class
  • Add archive and unarchive commands to plan_cli/commands/projects.py

Phase 4: Tests
